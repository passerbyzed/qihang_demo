1. **打开原型**  
   双击 `pm02-prototype-demo.html` 或在浏览器访问：

## 🔍 业务规则（已实现）

### 危机识别
- **自伤类**: 不想活、自杀、想消失 → 立即停应答
- **暴力类**: 打孩子、虐待 → 立即停应答
- **医疗类**: 多动症、抑郁症、吃药 → 拒绝诊断 + 转人工

### 风险分级
- **3 级（高危）**: 命中危机词 → AI 只做 1 次首响，之后禁止应答
- **2 级（中危）**: 投诉退费、医疗越界 → AI 只做安抚 + 转接
- **1 级（普通）**: 普通咨询 → AI 可继续答（最多 2 轮）

### 热度判断
基于急迫词（急、马上、今天）+ 问号/感叹号数量：
- **热度 3**: ≥3 个急迫信号
- **热度 2**: 1-2 个信号
- **热度 1**: 无明显急迫信号

### 知识库检索
1. 危机场景 → 固定话术模板
2. 否则按关键词匹配 → 最多返回 3 条
3. 无匹配时按意图返回对应分类

## 📊 API 接口

### POST `/api/analyze`

分析用户消息并生成首响

**请求体：**
```json
{
  "text": "孩子说不想活了，怎么办",
  "platform": "微信",
  "who": "家长·李女士"
}
```

**响应：**
```json
{
  "intent": "求方案",
  "risk": 3,
  "heat": 3,
  "basis": "命中危机词「不想活」→ 立即停应答转人工",
  "advice": "今天上午 10 点前电话回访，先问孩子当下的安全情况，不推课",
  "owner": "组长 小彤",
  "first_response": "我是启航的在线助教...",
  "kb_source": "危机应对固定话术 v1.2 · 第 1 条",
  "kb_items": [...],
  "should_stop_ai": true
}
```

### POST `/api/continue`

AI 追加回复（第 2-3 轮）

**请求体：**
```json
{
  "text": "（用户追问）",
  "history": [
    {"role": "user", "content": "..."},
    {"role": "assistant", "content": "..."}
  ],
  "intent": "问价格",
  "kb_items": [...]
}
```

**响应：**
```json
{
  "response": "试听是一节 60 分钟...",
  "kb_source": "AI 追加回复"
}
```

## ⚙️ 配置说明

### 修改知识库

编辑 `knowledge_base.json`：

```json
{
  "crisis_keywords": {
    "self_harm": ["不想活", "自杀", ...]  // 危机关键词
  },
  "intent_patterns": {
    "问价格": ["多少钱", "收费", ...]     // 意图匹配规则
  },
  "knowledge_items": [
    {
      "id": "kb_001",
      "category": "危机应对",
      "title": "...",
      "content": "...",
      "trigger_keywords": [...],          // 触发词
      "response_template": "..."          // 固定话术（可选）
    }
  ]
}
```

修改后**无需重启服务**，下次 API 调用会自动重新加载。

### 调整 DeepSeek 参数

编辑 `app.py` 中的 `generate_first_response()` 函数：

```python
response = client.chat.completions.create(
    model="deepseek-chat",
    temperature=0.3,  # 降低随机性（0-1，越低越确定）
    max_tokens=200    # 最大生成长度
)
```

## 🐛 常见问题

### Q1: 点击"发送到原型"后没反应？

**检查清单：**
1. 后端服务是否启动？（终端应显示 "running on http://0.0.0.0:5000"）
2. 浏览器控制台是否有错误？（F12 打开开发者工具）
3. API Key 是否正确配置？

### Q2: API 调用失败 "Authentication failed"

- DeepSeek API Key 未配置或错误
- 检查环境变量或 `app.py` 第 15 行

### Q3: 知识库修改后没生效

- `knowledge_base.json` 语法错误（检查逗号、引号）
- 重启后端服务：`Ctrl+C` 停止，重新 `python app.py`

### Q4: CORS 跨域错误

- 已在 `app.py` 第 12 行配置 `CORS(app)`
- 如果仍报错，检查浏览器是否禁用跨域（或用 `--disable-web-security` 启动浏览器，仅测试用）
